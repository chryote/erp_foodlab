## Feature: HR / EmployeeShiftAssignment
- **Table:** `employee_shift_assignments`
  - `id` (`bigIncrements`)
  - `company_id` (`foreignId` -> `companies.id`, `restrictOnDelete()`)
  - `employee_id` (`foreignId` -> `employees.id`, `restrictOnDelete()`)
  - `employee_shift_id` (`foreignId` -> `employee_shifts.id`, `restrictOnDelete()`)
  - `effective_date` (`date`)
  - `end_date` (`date`, nullable — `NULL` means currently active/ongoing)
  - `notes` (`string(255)`, nullable)
  - `timestamps()`, `softDeletes()`
- **Schema & DB Guardrails:**
  - **Money / Totals:** N/A
  - **Tenant & FKs:** Scoped to `company_id`; explicit FKs on `company_id`, `employee_id`, and `employee_shift_id`, all with `restrictOnDelete()`
  - **Soft-Delete Uniqueness:** Generated `active_flag` (`unsignedTinyInteger()->nullable()->storedAs('IF(deleted_at IS NULL, 1, NULL)')`, add `'active_flag'` to Model `$hidden`); `unique(['company_id', 'employee_id', 'effective_date', 'active_flag'])`
  - **Indexing:** Composite `(company_id, deleted_at)` and `(employee_id, effective_date, end_date)`; no standalone indexes on `created_at`, `updated_at`, or `deleted_at`
- **Enum (`app/Enums/`):** N/A (active status is derived from `effective_date` / `end_date`)
- **Relations:** `belongsTo(Company::class)`, `belongsTo(Employee::class)`, `belongsTo(EmployeeShift::class)`
- **Endpoints (`/api/v1/modules/hr/employee-shift-assignments`):** `index`, `store`, `show`, `update`, `destroy`
- **QueryBuilder (`Service::list`):** filters=[`company_id`, `employee_id`, `employee_shift_id`, `effective_date`, `end_date`], sorts=[`effective_date`, `end_date`, `created_at`], includes=[`company`, `employee`, `employeeShift`]
- **Safety / Business Rules:**
  - Validate `employee_id` and `employee_shift_id` belong to the same `company_id`
  - Validate `end_date >= effective_date` when `end_date` is provided
  - Reject overlapping active date ranges for the same `employee_id` inside `DB::transaction()` (with `lockForUpdate()` on the employee's active assignments)
- **Seeder (`database/seeders/DatabaseSeeder.php`):** idempotent initial shift assignment for each seeded employee (`updateOrCreate` / `withTrashed()` on `(company_id, employee_id, effective_date)` inside `DB::transaction()`, end with `Cache::flush()`); assert `employee_shift_assignments` populated in `SystemIntegrityTest`
- **Pest Test (`tests/Feature/EmployeeShiftAssignmentTest.php`):** CRUD, filters, 422 validation (cross-company mismatch, `end_date < effective_date`, overlapping date ranges), soft delete, active-duplicate rejection + re-create after soft delete
- **Verify:** `php artisan migrate:fresh --seed` (and repeat `db:seed`), `make schema-dump`, `make test-filter FILTER=EmployeeShiftAssignmentTest`
