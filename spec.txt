# ERP Feature Spec: CPO — Ingredient (`ingredients`)

## Feature: CPO
- **Table:** `ingredients`
  - `id` (`bigIncrements`, PK)
  - `default_package_id` (`foreignId` -> `default_packages.id`, `restrictOnDelete()`)
  - `item_id` (`foreignId` -> `items.id`, `restrictOnDelete()`)
  - `price` (`decimal(18, 2)`, default `0.00`)
  - `created_at`, `updated_at` (`timestamps`)
  - `deleted_at` (`softDeletes`)
  - `active_flag` (`unsignedTinyInteger('active_flag')->nullable()->virtualAs('CASE WHEN deleted_at IS NULL THEN 1 ELSE NULL END')`)
  - **Constraints & Indexes:**
    - `unique(['default_package_id', 'item_id', 'active_flag'], 'ingredients_pkg_item_active_unique')`
    - `index(['deleted_at', 'default_package_id', 'id'])`
    - `index(['deleted_at', 'item_id', 'id'])`
- **Schema & DB Guardrails:**
  - **Money / Totals:** `price` is `decimal(18, 2)` (never `double` or `float`)
  - **FKs:** Explicit FK constraints with `restrictOnDelete()` on `default_package_id` and `item_id` (existing `items` table from `mysql-schema.sql`[cite: 1])
  - **Soft-Delete Uniqueness:** Generated `active_flag` virtual column (`'active_flag'` in Model `$hidden`), unique active `(default_package_id, item_id)` so an item cannot be duplicated inside the same active package
  - **Indexing:** Composite `(deleted_at, default_package_id, id)` and `(deleted_at, item_id, id)` matching `defaultSort` and frequent parent lookups; no standalone indexes on `created_at`, `updated_at`, `deleted_at`
- **Enum (`app/Enums/`):** None
- **Relations:**
  - `belongsTo(DefaultPackage::class)`
  - `belongsTo(Item::class)`
- **Endpoints (`/api/v1/modules/cpo/ingredients`):** `index`, `store`, `show`, `update` (`PUT` + partial `PATCH`), `destroy`
- **QueryBuilder & Speed Guardrails (`IngredientService::list`):**
  - `filters=['default_package_id', 'item_id', 'min_price', 'max_price']`
  - `sorts=['id', 'default_package_id', 'item_id', 'price', 'created_at']` (default: `id`)
  - `includes=['defaultPackage', 'item']`
  - Cap pagination via `IndexQuery::paginate()` (`MAX_PER_PAGE = 100`); never allow unbounded `per_page`
  - Never use `LIKE` on `decimal`/numeric columns (`price`, IDs) — use exact or range comparison
  - Never run a duplicate uncached aggregate query (`SUM`/`COUNT`) on `index()` when an unpaginated collection is already fetched or cached
  - Eager-load default relations (`defaultPackage`, `item`) via `IndexQuery::withDefaultRelations()` (zero N+1 queries)
- **Validation & Safety Rules (`IngredientRequest` + `IngredientService`):**
  - Validate active uniqueness in `FormRequest::after()` (`WriteGuard::existsCaseInsensitive()` on `['default_package_id', 'item_id']`, with partial `PATCH` fallback to route model values) AND inside `DB::transaction()` via `WriteGuard::assertUniqueActive(..., sharedLock: true)`
  - Support partial `PATCH` updates (`sometimes` on `PATCH`) and fallback to existing model values
  - Enforce numeric bounds on `price`: `numeric`, `min:0`, `max:9999999999999999.99`, `decimal:0,2`
  - `DB::transaction()` on all writes; `lockForUpdate()` on row updates/deletes; re-verify active parent rows (`default_packages`, `items`) inside the transaction using `->whereNull('deleted_at')->sharedLock()`
  - On `destroy`, soft-delete row and forget all dependent caches
  - Transactional `POST`s rely on global `EnforceIdempotencyKey` middleware (`Idempotency-Key` header) to deduplicate client retries
- **Seeder (`database/seeders/DatabaseSeeder.php`):** Idempotent sample data (`default_package_id: 1`, `item_id: 1`, `price: 1.00` from reference[cite: 2] via `updateOrCreate` / `withTrashed()` on `['default_package_id', 'item_id']` inside `DB::transaction()`, end with `Cache::flush()`); assert table populated in `SystemIntegrityTest`
- **Pest Tests:**
  - Feature test (`tests/Feature/IngredientTest.php`): CRUD (`PUT` + partial `PATCH`), filters/sorts/includes, 422 validation (decimal bounds, inactive/missing parent FKs), soft delete, active-duplicate rejection + re-create after soft delete
  - Guardrail test (`tests/Unit/ApiPatternGuardrailsTest.php`): query-count/N+1 bounds, cache hit 0-query checks, `per_page` cap, schema/model `active_flag` & `$hidden`, Request/Service anti-duplication & `Idempotency-Key` checks
- **Verify:** `php artisan migrate:fresh --seed` (and repeat `db:seed`), `make schema-dump`, `make test-filter FILTER=IngredientTest`, `make test-filter FILTER=ApiPatternGuardrailsTest`
